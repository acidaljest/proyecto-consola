# Gestor de Gastos Personales - Proyecto Módulo 5

## Descripción

Aplicación de consola desarrollada en JavaScript como proyecto de cierre del
Módulo 5: Fundamentos de programación en JavaScript. Permite al usuario
registrar, visualizar, filtrar y clasificar sus gastos personales.

## Estructura del proyecto

/index.html
/app.js
/styles.css
/README.md

## Cómo ejecutarlo

1. Abrir el archivo `app.js` en un editor de código.
2. Abrir cualquier archivo HTML vacío que enlace este script, o pegar el
   código directamente en la consola del navegador (F12 → Consola).
3. Seguir las instrucciones que aparecen en pantalla mediante `prompt()`.

## Funcionalidades

- Ingreso de nombre de usuario con `prompt()` y `alert()`.
- Registro de gastos como objetos (descripción, monto, categoría).
- Cálculo del total de gastos.
- Filtrado de gastos por categoría.
- Clasificación de gastos en "bajo", "medio" o "alto" según su monto.
- Menú interactivo controlado con un ciclo `while` y `switch`.

## Conceptos aplicados

- **Variables:** `let` y `const` según corresponda.
- **Condicionales:** `if/else` y `switch`.
- **Ciclos:** `while` para el menú, `for` y `forEach` para recorrer arreglos.
- **Funciones:** cada acción del programa está modularizada en su propia función.
- **Arreglos y objetos:** los gastos se almacenan como un arreglo de objetos.
- **Validaciones:** se valida que el monto ingresado sea un número válido y mayor a 0.
